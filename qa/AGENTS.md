# QA DOX

## Purpose

Own deterministic visual and metric evidence used to pass or fail gates.

## Ownership

Camera manifests, comparison contact sheets, mismatch logs, geometry audits, and acceptance records.

## Local Contracts

- QA cameras are stable identifiers.
- Do not move an accepted camera casually; camera changes must be documented.
- Geometry review precedes material/lighting review.
- Acceptance vocabulary: PASS / PASS WITH DOCUMENTED EXCEPTION / FAIL.

## Work Guidance

Use automated capture/contact-sheet generation where available.

## Verification

Every applicable gate must point to committed evidence, not chat-only observations.

## Child DOX Index

None.
