# Reference Standard

## Folder model

Organize reference records by named map area, not by random download session.

Minimum area taxonomy:
- T Spawn
- Outside Long
- Long Doors
- Pit
- Long A
- A Site
- Short / Catwalk
- Top Mid
- Mid
- CT Mid
- CT Spawn
- B Doors
- B Site
- Upper Tunnels
- Lower Tunnels
- connectors/transition spaces

Add areas when the geometry requires finer separation.

## Required views per critical area

Where available, collect:
- top-down/plan clue;
- forward traversal view;
- reverse traversal view;
- left/right wall read;
- elevation/stair/ramp read;
- doorway/arch proportion clue;
- long sightline clue.

## Provenance

Every reference entry must record:
- source URL or local source identifier;
- creator/publisher when known;
- date accessed;
- area;
- view direction;
- intended use: geometry / material / lighting / prop / signage / scale;
- confidence;
- licensing/reuse note.

Do not commit copyrighted source images unless redistribution is permitted. When in doubt, store the URL/metadata and local-only filename, not the media itself.

## Measurement discipline

Prefer:
1. direct measurement from an authorized editor/source;
2. repeated in-game measurement with a known scale anchor;
3. triangulation from multiple views;
4. single-view estimation only as a last resort.

Never silently promote an estimate to a confirmed measurement.
