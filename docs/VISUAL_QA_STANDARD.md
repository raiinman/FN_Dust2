# Visual QA Standard

## Principle

The agent must be able to see and grade its own work.

Every major geometry or art pass produces repeatable fixed-camera evidence.

## Camera classes

Create cameras for:
- entry into each named area;
- reverse view out of each named area;
- long sightlines;
- critical door/arch proportions;
- elevation transitions;
- hero compositions.

Start with at least these IDs:
- QA_TSPAWN_001
- QA_LONG_001
- QA_LONG_002
- QA_A_001
- QA_SHORT_001
- QA_MID_001
- QA_MID_002
- QA_CT_001
- QA_B_001
- QA_TUNNELS_UPPER_001
- QA_TUNNELS_LOWER_001

Expand as required.

## Evidence cycle

For each pass:
1. render/capture every required camera;
2. pair with the best available reference;
3. compare geometry first, then art;
4. record mismatches;
5. fix;
6. re-capture;
7. preserve the accepted contact sheet and notes.

## Geometry review order

Check:
1. horizon/elevation;
2. large silhouette;
3. opening position/size;
4. route width;
5. cover/occlusion;
6. perspective convergence;
7. secondary shape.

Do not score textures while major geometry is wrong.

## Art review order

Check:
1. value/readability;
2. material family;
3. roughness response;
4. macro color variation;
5. edge/wear breakup;
6. prop density;
7. lighting continuity;
8. close/mid/far detail balance.

## Acceptance language

Use:
- PASS
- PASS WITH DOCUMENTED EXCEPTION
- FAIL

Avoid "pretty good", "close enough", or "looks fine" without specifics.
